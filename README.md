# 计算机存储技术 3D 原理展示

基于 **Three.js** 的交互式教学项目,用 3D 动画演示计算机各类存储技术的工作原理。

## 运行方式

```bash
npm install
npm start
```

然后浏览器打开 http://localhost:8137 (ES Module 需要 HTTP 服务,不能直接双击 index.html)。

## 四个场景

| 场景 | 内容 | 可交互演示 |
|------|------|-----------|
| 🏛️ 存储层级 | 寄存器 → Cache → 内存 → SSD → HDD 金字塔 | 数据读取之旅、缓存命中 |
| 🧠 内存 DRAM | 1T1C 存储单元(晶体管+电容)、字线/位线行列寻址 | 写1充电、写0放电、破坏性读取+回写、电荷泄漏、整行刷新 |
| ⚡ 固态硬盘 SSD | 浮栅晶体管剖面、量子隧穿、闪存块/页阵列 | 编程(电子注入)、擦除、断电数据保持、按页写入、按块擦除+磨损计数 |
| 💿 机械硬盘 HDD | 旋转盘片、磁道/扇区、磁畴、磁头臂 | 寻道+旋转等待+读取全流程、写入(磁畴翻转)、转速切换、磁畴俯视特写 |

## 操作说明

- 顶部标签页切换场景
- 左键拖动旋转视角,滚轮缩放,右键平移
- 右下角按钮触发各原理动画,左下角面板是原理讲解,顶部黄色状态条实时解说动画步骤

## 技术结构

```
index.html          页面骨架 + import map(本地 node_modules 加载 three,可离线运行)
style.css           UI 样式
js/main.js          渲染器 + 场景管理器 + UI 接口
js/utils.js         中文文字精灵、缓动动画系统、发光电子等公共工具
js/scenes/
  hierarchy.js      存储层级金字塔
  dram.js           内存 DRAM 原理
  ssd.js            SSD NAND 闪存原理
  hdd.js            机械硬盘原理
```
