# 计算机存储技术 3D 原理展示

基于 **Three.js** 的交互式教学项目,用写实的 3D 模型和动画演示计算机各类存储技术的工作原理。
所有模型、纹理均由代码程序化生成(无外部图片/模型资源),按真实尺寸建模。

## 运行方式

```bash
npm install
npm start
```

然后浏览器打开 http://localhost:8137 (ES Module 需要 HTTP 服务,不能直接双击 index.html)。
网址末尾可加 `#hierarchy` / `#dram` / `#ssd` / `#hdd` 直接打开对应场景。

## 四个场景

| 场景 | 模型 | 可交互演示 |
|------|------|-----------|
| 🏛️ 存储层级 | Micro-ATX 主板(CPU 插座、供电散热片、内存插槽、M.2、芯片组、SATA)+ SATA 线连接的 3.5" 硬盘;可揭开 CPU 顶盖看晶粒版图(寄存器堆 / L1 / L2 / L3 / 内存控制器) | 从硬盘读取的完整旅程(逐级未命中 → 缺页 → 磁盘 I/O → DMA → 逐级复制)、从 SSD 读取、缓存命中;右上角延迟阶梯与累计耗时 |
| 🧠 内存 DRAM | DDR5 内存条(8 颗颗粒、PMIC、SPD Hub、288 针金手指)插在主板插槽上 → 开封的 DRAM 晶粒(16 个 Bank)→ 8×8 的 1T1C 阵列(圆柱电容、斜置有源区、埋入式字线、位线、灵敏放大器、行译码器) | 写 1 / 写 0、读取(预充电 → 激活整行 → 电荷共享 → 灵敏放大 → 回写,示波器显示位线电压)、电荷泄漏、逐行刷新;点击电容选择目标单元 |
| ⚡ 固态硬盘 SSD | M.2 2280 NVMe 固态硬盘(主控、DRAM 缓存、2 颗 NAND)→ 3D NAND 堆叠剖面(垂直沟道、多层字线、台阶接触)→ 电荷捕获单元放大剖面 | 编程(F-N 隧穿)、读取(阈值电压 / 串电流)、擦除(氧化层损伤累积)、断电保持;按页写入、异地更新 (FTL)、垃圾回收 + 块擦除,右上角页状态表 |
| 💿 机械硬盘 HDD | 开盖的 3.5" 硬盘:压铸铝底座、3 张镜面盘片(圆周拉丝各向异性高光)、主轴与压盘、E 型块磁头臂、不锈钢悬臂与滑块、音圈电机、停泊坡道、随动柔性排线、SATA 接口 → 垂直磁记录微观结构(磁性晶粒、软磁底层、写磁极与线圈、TMR 读传感器) | 读 / 写随机扇区(寻道 + 旋转等待 + 传输,显示真实毫秒数)、磁头停泊 / 加载、切换转速、开合顶盖;微观写入(磁场线 + 晶粒翻转)与读出波形 |

## 操作说明

- 顶部标签页切换场景,其下的"视角"按钮在各个工位之间飞行切换
- 左键拖动旋转视角,滚轮缩放,右键平移
- 右下角按钮触发各原理动画;左下角是原理讲解;顶部状态条实时解说动画步骤;右上角为实时数据面板
- 底部"🏷️ 标注"按钮可隐藏 / 显示 3D 标注(标注会按镜头远近自动淡入淡出)

## 渲染技术

- PBR 材质(金属度 / 粗糙度、清漆、虹彩、各向异性)+ 程序化摄影棚环境贴图反射
- 柔和阴影、Khronos PBR Neutral 色调映射、4× MSAA
- **选择性辉光**:单独渲染一遍只含发光体的画面做 Bloom,金属高光不会被误糊成光晕
- 3D 标注使用 CSS2D(HTML 文字,任何缩放下都清晰)
- 首次进入场景时异步编译着色器,避免卡顿

## 目录结构

```
index.html            页面骨架 + import map(three 从 jsDelivr CDN 加载)
style.css             UI 样式(含手机竖屏布局)
js/main.js            渲染器、后期处理、场景管理、镜头飞行、点选、UI 接口
js/utils.js           缓动动画(支持 await)、发光粒子、资源释放
js/lib/
  textures.js         Canvas 程序化纹理:PCB 走线与丝印、芯片刻字、标签贴纸、晶粒版图、拉丝/噪声等
  materials.js        PBR 材质库(镀金、拉丝铝、压铸铝、镜面盘片、硅晶粒、氧化层……)
  geom.js             几何工具:挤出、剖切圆柱壳、扁平排线、批量实例
  stage.js            摄影棚布光、台面、环境贴图
  labels.js           带引线的 3D 标注(按距离淡入淡出)
  bloom.js            选择性辉光
js/models/
  hdd.js              3.5" 机械硬盘
  dimm.js             DDR5 内存条 + 插槽
  m2ssd.js            M.2 2280 固态硬盘 + 插座
  cpu.js              LGA CPU + 插座(可拆顶盖,晶粒版图)
  motherboard.js      Micro-ATX 主板
js/scenes/
  hierarchy.js        存储层级
  dram.js             内存 DRAM 原理
  ssd.js              SSD 3D NAND 闪存原理
  hdd.js              机械硬盘原理
```
